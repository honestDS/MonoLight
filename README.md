# MonoLight

> 一个重构的高性能 AI 框架。

## 🛠 项目概述
MonoLight 是一个使用 Python 重构的现代化 AI 框架，专注于性能、低耦合和开发者体验。

## 🚀 快速开始

### 环境要求
* Python 3.10 或更高版本
* SQLite

### 安装步骤
```bash
pip install -r requirements.txt
```

### 配置说明
拷贝 `.env.example` 为 `.env` 并根据环境修改配置。

### 启动项目
```bash
python main.py
```
