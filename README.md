# MonoLight

一个由后端配置驱动的极简自主 Agent 交互框架。管理员通过后端 Profile 与 Prompt 库集中定义模型行为，系统内置 Agent 循环执行引擎，支持通过工具链完成物理世界的任务执行。

## 1. 核心特性
- **自主 Agent 架构**: 内置 Dispatcher 循环机制，支持 AI 自主调用工具链完成复杂逻辑。
- **配置驱动**: 模型参数、采样策略与提示词模版均由后端 Profile 强制定义。
- **提示词资产管理**: 独立的 PromptLibrary 支持多套提示词随时切换与复用。
- **自动化上下文管理**: 支持 tool 角色消息解析，内置动态 Token 裁减算法。
- **物理工具集成**: 首发支持 ShellExecutor，允许 AI 在受控环境下执行系统指令。
- **全异步架构**: 基于 FastAPI 与 SQLAlchemy 的高性能并发处理。
