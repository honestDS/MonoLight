# MonoLight

> 一个由后端配置驱动的极简 AI 交互框架。

## 🛠 项目概述
MonoLight 专注于后端完全管控的 AI 体验。通过 Profile 系统，管理员可以集中定义模型行为，而前端只需发送纯文本消息。这种设计消除了前端逻辑的复杂性，确保了生成结果的高度可控与一致性。

## 🏗 技术架构
👉 **[ARCHITECTURE.md](./ARCHITECTURE.md)**

## 🚀 核心特性
1. **配置驱动 (Profile-Driven)**: 所有模型参数、采样策略均由后端 Profile 强制定义。
2. **极简协议**: 客户端仅需发送文本消息，无需关心模型底层参数。
3. **多提供商支持**: 灵活接入不同厂商的模型 API。
4. **全异步架构**: 基于 FastAPI 与 SQLAlchemy 的高性能并发处理。
