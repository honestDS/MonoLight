# MonoLight

一个由后端配置驱动的极简 AI 交互框架。管理员通过后端 Profile 与 Prompt 库集中定义模型行为，前端仅需处理文本交互，消除了客户端逻辑的复杂性，确保了 AI 输出的一致性与可控性。

## 1. 未来规划
- **Agent 执行器**: 构建自主执行引擎，支持 AI 任务的自循环执行与复杂链路拆解。
- **多用户系统**: 引入完整的用户权限体系与多角色管理。
- **多用户会话隔离**: 实现物理层面的会话与数据隔离，确保多租户环境下的安全性。

## 2. 技术架构
详细文档请参考 [ARCHITECTURE.md](./ARCHITECTURE.md)

## 3. 核心特性
- **配置驱动**: 模型参数、采样策略与提示词模版均由后端 Profile 强制定义。
- **提示词资产管理**: 独立的 PromptLibrary 支持多套提示词随时切换与复用。
- **自动化上下文管理**: 内置动态 Token 裁减算法，支持长效对话且确保对话完整性。
- **会话持久化**: 自动记录多会话历史，支持全量历史回溯。
- **灵活鉴权**: 支持可配置的 JWT Token 有效期，降低交互成本。
- **高度兼容**: 核心调度器支持虚模型提供商占位，便于快速原型开发。
- **全异步架构**: 基于 FastAPI 与 SQLAlchemy 的高性能并发处理。
