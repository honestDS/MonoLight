# MonoLight

> 一个由后端配置驱动的极简 AI 交互框架。

## 🛠 项目概述
MonoLight 专注于后端完全管控的 AI 体验。通过 Profile 系统，管理员可以集中定义模型行为，而前端只需发送纯文本消息。这种设计消除了前端逻辑的复杂性，确保了生成结果的高度可控与一致性。

## 🚀 核心特性
1. **配置驱动 (Profile-Driven)**: 所有模型参数、采样策略均由后端 Profile 强制定义。
2. **自动化上下文管理**: 内置动态 Token 裁减算法，支持长效对话且确保对话对完整性。
3. **会话持久化**: 自动记录并管理多会话对话历史，支持历史回溯。
4. **长效鉴权**: 支持可配置的 JWT Token 有效期（默认 7 天），降低交互成本。
5. **极简协议**: 客户端仅需发送文本消息，无需关心模型底层参数。
6. **全异步架构**: 基于 FastAPI 与 SQLAlchemy 的高性能并发处理。
